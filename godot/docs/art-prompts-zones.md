# Island backdrop prompts (ready to paste)

Generated by `godot/tools/art/build_icon_prompts.py` together with the icon prompts (edit the zone table there, rerun, and this file and `D:\AI\tools\icons.json` are rebuilt). One painted backdrop per expedition island, shown behind the live battle.

## What the game does with them

- **10 backdrops**, one per island in `godot/data/zones.json`. Game file: `godot/assets/zones/<id>.jpg` (a `.png` works too). Until a file exists the game draws a simple landscape in the island's type colour, so they can be added one at a time.
- The battle view is roughly square, so the backdrops are **square (1024x1024)**; the game scales them to cover the view and trims a little off the sides on wider windows.
- **The ground line matters.** Creatures stand with their feet at **84 percent of the height** (front row) and **77 percent** (back row), so the bottom third of each picture must be flat, open ground. The game darkens the lower half slightly for the name labels and health bars. Reject candidates where the ground is tilted, cluttered, or ends above the bottom third.

## How to use these

The same **Flux.2 [Klein] 4B text-to-image** graph as the icons (8 steps, CFG 1.0, its default 1024x1024), through `icon_runner.py`:
```
python icon_runner.py run --group zone --count 4       4 candidates per island
python icon_runner.py sheet --group zone               contact sheet
python icon_runner.py pick whisperleaf-hollow 2         approve one (D:\AI\icons\approved\zones\)
python icon_runner.py fix whisperleaf-hollow 2 --prompt "..."   targeted edit
python icon_runner.py finish --group zone              square-crop to 1024, save as JPEG and copy into godot/assets/zones/
```
No key colour and no cutout: backdrops are used as they are.

**Picking checklist:**
- Flat ground across the whole bottom third, level from edge to edge, with nothing standing on it in the middle.
- No creatures, animals or people (models like to add a small figure; reject those).
- Busy detail belongs at the far left and right and in the distance. The centre should be calm enough for three creatures a side.
- Deep, slightly muted colour: the creatures are bright and outlined, and should pop in front. Very bright or white skies wash them out.
- No text or frames. Seen from the side, not from above.
