# Icon prompts (ready to paste)

Generated by `godot/tools/art/build_icon_prompts.py` (edit the table there, rerun, and this file and `D:\AI\tools\icons.json` are rebuilt). The creature sprite prompts are the separate `docs/art-prompts.md` on `main`.

## What this covers

- **111 item icons**: every item in `godot/data/items.json` (logs, herbs, ores, fish, salvage, bars, meals, components, threads, vessels, parts, rare finds). Game file: `godot/assets/icons/items/<id>.png`.
- **40 interface icons**: currencies, the 11 skills, navigation, stats and markers. 2 of them reuse an item icon (no generation). Game file: `godot/assets/icons/ui/<id>.png`.
- **149 images to generate in total.**
- The game already has generated SVG placeholders for all of these, drawn in the same outlined style. **A PNG with the same name replaces the SVG automatically** (the game prefers `.png` when it exists), so icons can be swapped in one at a time.
- **Not covered:** eggs (drawn by a shader in the game), the island battle backdrops (their own file, `docs/art-prompts-zones.md`), and the hybrid creature sprites (those belong in the creature pipeline, `build_prompts.py`).

## How to use these

One stage only (icons have no forms), with the **Flux.2 [Klein] 4B text-to-image** graph, **8 steps, CFG 1.0**, 1024x1024, the same graph the creature Form 1s use.

The fast way is `icon_runner.py` (in `godot/tools/art/`; it uses your `batch_runner.py` and `sprite_tools.py` from `D:\AI\tools`):
```
python icon_runner.py status                          what is approved, generated, still to do
python icon_runner.py run --group item --count 4       4 candidates per item icon (resumable; --only a,b; --more)
python icon_runner.py run --group ui --count 4
python icon_runner.py sheet --group item               contact sheet of the candidates, numbered
python icon_runner.py pick oak-log 3                   approve candidate 3 (copies it to D:\AI\icons\approved\items\)
python icon_runner.py fix oak-log 3 --prompt "..."      targeted edit of one candidate, like batch_runner fix
python icon_runner.py finish                           cut out every approved icon to 256 px and copy it into the game
```
Or by hand: paste a prompt below into the text-to-image graph, pick the best, and save it as `D:\AI\icons\approved\items\<id>.png` (or `...\ui\<id>.png`), then run `icon_runner.py finish`.

**Estimated time:** about 9 s per image, so 4 candidates for all 149 icons is about 89 minutes of generation.

**Key colour:** magenta `#FF00FF`, except **green `#00FF00` for anything pink, purple, violet, lilac or rose** (same rule as the creatures: those colours sit too close to magenta for a clean cut). Each prompt already has the right one; `finish` measures the background from the image border either way.

**Picking checklist:**
- One object only: reject extra copies, a second smaller object, or scattered crumbs and specks around it.
- Reads at 24 px: squint or zoom out. Thin details vanish; a bold silhouette and two or three strong colours win.
- No text, letters or numbers anywhere (models like to write on coins, books and chips).
- No floor shadow, no glow or haze around the outline, nothing see-through (the key colour shows through glass and ruins the cut).
- Same family: outline weight and saturation should match the icons you already approved. Put the new pick next to the others on the contact sheet before approving it.
- Sizes: the game shows icons from 18 to 84 px. Framing is centred with a small margin; `finish` crops to the object anyway.

**The style line** at the start of every prompt matches the creature sprites (soft painterly, clean outlines, vibrant, chunky), so the icons sit next to the Aetherlings. All icons use the same dark indigo outline, the game's ink colour.
